Compression


Files can be very big at times, so it's useful to have a way to lessen their sizes to reduce slowdown and. Compression is the way of reducing file size immensely.

As stated in the binary systems website, a file is made up out of bytes, which are made up out of strings of binary code. If a specific string of code is repeated in a collection of strings, it can be summed up by a specific binary number of itself: an A could be 0, B 1, C 10, et cetera. A specific string of code is reduced tenfold, now consisting of smaller, bite-sized strings of binary, resulting in a smaller piece of code and thus a smaller piece of a file, ultimately making a smaller file all in all.

There are two types of compression: lossy compression and lossless compression. Lossy compression is compression where, as the name implies, pieces of the file are permanently lost and thus erased from the file after compressing. An example is with an image compressor: by removing useless data can reduce the amount of pixels in an image and reduce picture quality. Lossless compression, however, doesn't reduce file size at all.
